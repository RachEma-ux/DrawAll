# Outils de dessin de la planche — table d'amélioration

Date : 10 octobre 2026. Sources : inventaire du code de DrawAll (état `48b5757`, fichiers `src/App.tsx`, `src/components/CanvasView.tsx`, `src/lib/*`) et analyse des fichiers partagés ([rapport par catégorie](Rapport_extensions_SketchUp_par_categorie.md)) — extension DBS MetalFab v2.2. SU Splat n'a pas pu être lu (fichier trop volumineux pour le connecteur Drive) et n'alimente donc aucune ligne.

Version tableur : [Table_ameliorations_outils_planche.csv](Table_ameliorations_outils_planche.csv) (séparateur `;`, UTF-8, s'ouvre directement dans Excel ou Google Sheets).

Les fonctionnalités sont reprises **fonctionnellement** : MetalFab est un logiciel commercial chiffré ; aucun code, icône ni donnée n'est copié.

## Ordre de réalisation proposé

1. **Catalogue de profils + matériaux avec densité** (lignes 12, 13, 18) : c'est le socle des autres améliorations ; il lève aussi la réserve « aucun catalogue inventé » du lot 13.4 en s'appuyant sur des gammes normalisées (EN 10365 pour les IPE/HEA/UPN, EN 10219 pour les tubes).
2. **Nomenclature enrichie** (ligne 17) : longueur, masse, coût, débit en barres.
3. **Dessiner depuis des arêtes, décalage de longueur, onglet** (lignes 3, 6, 8).
4. **Repérage automatique et sélection des identiques** (lignes 1, 16).
5. Le reste par ordre de priorité.

Chaque point deviendrait un lot de la [feuille de route](../DrawAll_Feuille_de_route.md) avec sa définition de fini (tests Vitest, recette Playwright). Ces lots relèvent du module « structure détaillée / bois / tôlerie », que la feuille de route classe aujourd'hui hors périmètre (P2/P3) : leur ouverture est une décision du maître d'ouvrage.
